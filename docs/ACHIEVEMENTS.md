# V1 achievements

The approved starter set contains six training milestones and two LoadToad personality badges.

| Badge | Rule |
| --- | --- |
| First Session | Complete every block of one planned training session. |
| Five Sessions Strong | Complete five planned training sessions. |
| Ten Sessions Strong | Complete ten planned training sessions. |
| Clean Finish | Complete every block of a training session with explicit clean confirmation. |
| Progress Earned | Earn an increase through two comparable clean block completions at a target that can increase. |
| Mock PFA Complete | Complete a full mock session, including its three mock components, with normal readiness. No official score is certified. |
| Toad Takes a Breather | Complete a recovery session; skipped recovery does not qualify. |
| Pond Regular | Save check-ins in four distinct weeks; they need not be consecutive. |

Achievements are derived from saved history whenever the screen opens. Duplicate session IDs and future records do not count. Legacy manual result logs do not establish session completion. Recovery earns its own badge and does not count toward the training-session milestones. Deleting qualifying history may remove a badge.

Progression metadata records whether a target can increase, so reaching an interval or submaximal ceiling cannot falsely earn Progress Earned. Earlier records without this metadata cannot establish an earned increase.

Run achievement checks with `node --test scripts/test-achievements.cjs`.
