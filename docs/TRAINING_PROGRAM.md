# LoadToad PT Training Program

This document is the product-level source of truth for the V1 training engine.

## Weekly structure

Users choose five training days. LoadToad keeps the underlying structure fixed at:

1. PFA technique / acceleration
2. Strength A — lower body + trunk
3. PFA controlled specific practice
4. Strength B — upper body + durability
5. PFA quality intervals or scheduled mock

The calendar days can vary, but the 3 PFA / 2 strength split stays intact.

## Training philosophy

- Train the selected PFA components specifically, but do not turn routine sessions into max-effort tests.
- Use submaximal volume for most push/core work.
- Keep hard conditioning separate from strength-support days.
- Progress only after clean successful sessions.
- Use low-impact cardio when impact is restricted or painful.
- Mobility and recovery are part of the program, not optional punishment for being sore.
- Exercise substitutions must preserve the purpose of the exercise whenever possible.
- Training should adapt to the user rather than forcing the user through a static calendar.

## PFA days

### PFA 1 — technique / acceleration

Purpose: event mechanics, acceleration, turns, running economy, and recoverable specific volume.

HAMR default:
- 5–10 minute warm-up
- 10 × 20 sec hard / 40 sec walk
- selected strength component: 3 sets at roughly 50–60% of baseline
- selected core component: 3 sets at roughly 50–60% of baseline

2-mile default:
- warm-up
- relaxed-fast strides / mechanics
- submaximal selected strength and core work

2 km walk default:
- brisk technique intervals
- submaximal selected strength and core work

### PFA 2 — controlled specific practice

Purpose: practice the real event while stopping before failure.

HAMR default:
- controlled HAMR
- stop roughly 2–4 shuttles before expected failure
- selected strength component: about 2 sets at 60% of baseline
- selected core component: about 2 sets at 60% of baseline

Run/walk paths use controlled tempo/event-specific work instead of racing the event.

### PFA 3 — quality / mock

Normal quality week:
- warm-up
- VO2-oriented intervals, typically up to 4 × 4 min hard / 3 min easy
- selected strength component: about 3 sets at 50% of baseline
- progressive core work

Mock week:
- one official-style attempt for the selected strength component
- one official-style attempt for the selected core component
- one official-style attempt for the selected cardio component

True max-effort PFA testing is intentionally limited. Routine work is not taken to failure.

## Strength-support days

### Strength A — lower body + trunk

Goal: leg strength, posterior-chain capacity, lower-leg durability, and trunk control without compromising the next PFA session.

Default movement categories:
- knee-dominant strength
- posterior chain
- calf/lower-leg work
- anti-rotation trunk work
- mobility reset

### Strength B — upper body + durability

Goal: support push performance, posture, shoulder balance, trunk control, and general durability.

Default movement categories:
- press
- pull
- secondary lower-body work
- anti-rotation trunk work
- mobility reset

Routine strength sets generally finish with 2–3 reps in reserve. Hard running is not stacked onto strength-support days.

## Progression

Progression is earned, not automatic.

After two clean successful sessions:
- rep-based work: +1 rep per work set
- plank: +5 sec per work set
- HAMR-specific target: roughly +2 shuttles when appropriate
- interval work: +1 interval when the training phase allows it
- easy walking: +5 min when recovery remains good

After repeated misses, hold or slightly reduce the target instead of forcing progression.

## Readiness

The active-workout flow will use a simple readiness check for energy, soreness, and pain.

- normal readiness: follow the plan
- reduced readiness: trim volume while keeping the training purpose
- high pain: replace hard work with recovery movement and avoid painful patterns

LoadToad adapts training; it does not diagnose injuries.

## Mobility and substitutions

User restrictions are saved in the profile. The exercise engine should substitute by training purpose, not merely delete exercises.

Examples:
- squat restricted + gym available → leg press in a tolerated range
- hip hinge / heavy spinal loading restricted → leg curl or supported hip work
- impact restricted → bike, elliptical, rower, stair climber, or walking depending on equipment
- wrist loading restricted → machine or neutral-grip pressing when available

An optional minimum-effective-dose trunk finisher such as Torture Twists may appear only when appropriate and pain-free. It is never required when the user's back or position does not tolerate it.

## Training phases

The exact PFA date determines the phase:

- Foundation: more than 8 weeks out
- Build: 5–8 weeks out
- Sharpen: 2–4 weeks out
- Taper: final 7 days

Volume decreases approaching the test while specificity is preserved.
